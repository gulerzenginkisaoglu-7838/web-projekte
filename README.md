# Web-Projekte  
 
HTML/CSS-Webseitenprojekte, erstellt im Rahmen der Umschulung zum Fachinformatiker Systemintegration (GFN).  
 
## Inhalt  
 
- **guler-portfolio/** — Persönliche Portfolio-Webseite  
- **gzk-pastel-site/** — Webseiten-Projekt im Pastell-Design  
- **spiele-arena/** — Interaktive Spiele-Sammlungsseite (HTML/CSS/JS)  
  - **backend/app.py** — Flask/Python-Backend mit Login, Registrierung und Passwort-Hashing (Umgebungsvariablen statt Hardcoding für Secret Key)  
  - **backend/php-mysql-version/** — PHP/MySQL-Backend-Alternative mit Prepared Statements  
  - **backend/infinityfree-version/** — Für InfinityFree-Hosting angepasste PHP-Version
